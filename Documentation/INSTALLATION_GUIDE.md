# FUNDED AI EA — INSTALLATION GUIDE

1. Extract the release package zip file.
2. In MT5, click `File -> Open Data Folder`.
3. Navigate to `MQL5/Experts/` and create folder `FundedAI`. Copy `FundedAI_EA.mq5` here.
4. Navigate to `MQL5/Include/` and create folder `FundedAI`. Copy all `.mqh` files here.
5. In MT5, open MetaEditor (`F4`), locate `FundedAI_EA.mq5`, and click **Compile**.
6. Verify 0 compilation errors in MetaEditor toolbox.
7. Return to MT5, drag `FundedAI_EA` onto your target chart.
